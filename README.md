# Netflix-Data-Cleaning-and-Analysis-SQL-Python-

This project demonstrates an end-to-end ELT (Extract, Load, Transform) workflow using the **Netflix** dataset. 
The goal is to clean, process, and analyze the data to uncover insights about Netflix's content library and trends.

Project Overview:

**Extract:**
Retrieve the Netflix dataset using the Kaggle API. This automated method ensures a seamless and reproducible data extraction process.

**Load:**
Loaded the raw dataset into Microsoft SQL Server (MSSQL) for structured data management, enabling efficient querying and analysis.

**Transform:**
Performed data cleaning and transformation directly in SQL. This includes:
Handling missing values and inconsistencies.
Formatting and standardizing data types.
Creating new tables and columns for enhanced analytics.

Analysis:
Perform comprehensive analysis using SQL and Python. Analyze content trends, regional preferences, release patterns, and more.

**Key Objectives**:
Clean and prepare the dataset for analysis using SQL and Python.
Implement best practices for an ELT pipeline to ensure reproducible and scalable workflows.
